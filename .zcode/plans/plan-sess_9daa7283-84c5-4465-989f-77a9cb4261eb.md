# Roulette — multiplayer shared-wheel game

Rides the existing crash-style round architecture (`game.RoundGame` + `round.Runner`): betting window → wheel spin → result → payouts, repeating per room. European single-zero (37 pockets, RTP 97.30%), Classic bet set: straight numbers (35:1), dozens/columns (2:1), red/black/odd/even/low/high (1:1). Multiple chips per player per round across spots. Phases: 18s betting / 2s "no more bets" / 6s spin / 6s settled (32s cycle, tunable). No `/api/v1/games` listing — roulette is room-only like crash, appearing live in the lobby and radial wheel.

## Backend (`services/backend`)

1. **Engine `internal/game/roulette/roulette.go` + `roulette_test.go`** — implement `game.RoundGame`: `ID() "roulette"`; `Phases()` (18s/2s/6s/6s); `Resolve(s *fair.Stream)` via existing `WeightedPick` over 37 equal weights → `RoundResult{Multiplier: 0, Payload: {"pocket", "color"}}` (provably fair, zero fairness-infra changes); `SettleBet(r, b)` comparing `b.Options.spot` to the pocket (zero kills all outside bets); `TheoreticalRTP() 36/37`. Spot catalog: `n0..n36`, `d1..d3`, `c1..c3`, `red/black/odd/even/low/high` with predicates + payout multipliers; `ValidateSpot()` optional interface for the intake. Table-driven tests: every spot type × representative pockets including zero rules + RTP sanity.

2. **Bets registry generalization `internal/round/bets.go`** — the one structural change: registry keyed `(userID, spot)` instead of one-bet-per-user (crash keeps `spot == ""`, behavior unchanged); settlement becomes an injected `SettleFunc(game.RoundResult, game.RoundBet)` — crash keeps its cashout logic, roulette injects `game.SettleBet`. New coded errors: `table_limit` (per-user round exposure cap = maxBet × 10), reuse `wrong_phase`/`insufficient_funds`.

3. **Intake `internal/round/intake.go`** — `place_bet` payload gains `spot` (validated via `ValidateSpot`); per-spot in-memory add with wallet rollback on debit failure (existing pattern); new `game_action: "clear_bets"` during betting_open → refund all the user's open bets in one idempotent tx, drop reservations; `bet_placed` broadcast gains `spot` + user's round total; `round_settlements` gains per-bet rows `{userId, spot, payoutCredits}`.

4. **Persistence** — `Persister.PlaceBet` gains a spot/options param; `db/queries/round_bets.sql` `InsertRoundBet` parameterized (currently hardcodes `'crash'`/`'bet'`); roulette rows: `action = "bet:" + idemKey` (keeps the `uq_bets_round_action` unique index meaningful, replay-safe via wallet idempotency), `outcome = {"spot": ...}`; new `ClearRoundBets` query (refund kind `refund`, idem `round:{r}:{u}:clear`, rows marked `:cleared`). `SettleRound` needs no change (already per-bet payouts, all-or-nothing tx).

5. **Runner tweak `internal/round/runner.go`** — `history` appends `result.Multiplier` (always 0 for roulette); add `HistoryValue func(RoundResult) float64` to `round.Config` (default: Multiplier) so roulette feeds winning pockets into the recent-results history that powers lobby + room strips. `LiveState` shape untouched — the lobby DTO's `recentCrashes` key carries recent pocket numbers.

6. **Wiring + rooms** — `cmd/gameserver/main.go`: `roundRegistry["roulette"] = roulette.New()`. New migration `000XX_roulette_rooms.sql`: three rooms mirroring existing tiers — Ground Floor 5–1,000, High Floor 25–2,500, Whale Room 100–10,000.

## Frontend (`apps/web`)

1. **`lib/roulette.ts`** — European wheel order, red set, `pocketColor`, the spot catalog (id, label, payout, `hits(pocket)`) shared by board, wheel and lobby card.

2. **`components/RouletteRoom.tsx`** (~1,100 lines, CrashRoom conventions: hand-rolled WS + `sockGen` guard, `room_snapshot`/`round_state`/`round_result`/`round_settlements`/`bet_placed`/`bet_ack`/`error`, optimistic `["me"]` balance):
   - **Betting board**: classic tableau (0 + 12×3 grid, dozens row, even-money row) of clickable cells; denomination chips 5/10/25/50/100 (existing `Chip` component); my stakes show as `ChipStack`s on spots; CLEAR button; total-staked readout; board live only during betting_open (countdown with last-3s beeps).
   - **Wheel** (pure CSS, no canvas — matches the codebase): 37 hard-stop conic-gradient pocket ring in true wheel order with rotated Silkscreen numbers; spins with accelerating blur during the 6s suspense phase (outcome hidden until result, like crash's climb); on `round_result` the ball drops into the pocket (`reelStop`), the wheel eases the winning pocket to the top marker, winning spots flash, payout banner counts up (`winTick`/`jackpot` for straights). "NO MORE BETS" strobe during locked.
   - **Panels**: players list (per-user total staked), recent-pockets history strip (colored chips), fits the existing scale()-to-fit room chrome with Backdrop.
   - Sends: `place_bet {credits, spot, idempotencyKey}`, `game_action {action: "clear_bets"}`.

3. **Lobby + dispatch** — `RouletteTableCard` in `page.tsx` (mini wheel + recent pockets) with a `gameId === "roulette"` branch in `LiveTableCard`; same branch in `RoomGate.tsx` → `RouletteRoom`; dev-only `?demo=` path in `app/rooms/[slug]/page.tsx` for visual testing without the backend.
