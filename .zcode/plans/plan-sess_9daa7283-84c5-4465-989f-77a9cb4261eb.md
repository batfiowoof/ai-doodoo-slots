# Radial Main Menu + Bigger Dialogs

Pure frontend work in `apps/web` — no backend/API changes, no new npm dependencies (animations = CSS keyframes + inline transitions, sounds = existing `lib/sound.ts` singleton).

## Part 1 — Radial main menu

**Rewrite the main area of `apps/web/app/page.tsx`; new `apps/web/components/RadialMenu.tsx`; new keyframes in `apps/web/app/globals.css`.**

### Structure (single wheel, everything on the wheel)

- `page.tsx` keeps all data plumbing (`useSession`, `useGames`, `useLobby`, `useDeposit`), the deposit toast (`notePop`), `AccountModal` wiring, Backdrop, and the resize-to-fit hook (retargeted to a new fixed stage size). The slim top bar keeps only the wordmark and SND ON/OFF toggle. Footer disclaimer stays.
- **Hub (center)**: big "RETRO CASINO" wordmark + credits odometer (`data-testid="credits"` preserved) + loading/error states ("OPENING THE FLOOR…" / "CASINO UNREACHABLE").
- **Outer ring — game nodes**, evenly spaced (radius adapts to count, ~4–7 nodes): each slots machine (PixelSymbol icon strip + name + RTP), blackjack (mini card fan), each live crash room (ship sprite, live multiplier tinted via existing `tierGlow`, pulsing LIVE badge), each live poker room (mini felt + seat dots + blinds). Node content is compact versions of today's card art; links preserved (`/play/{id}`, `/rooms/{slug}`) with per-kind sounds (slots/blackjack `click()`, poker `chipClink()`, crash `boost()`).
- **Inner orbit — action satellites** (smaller radius, offset angles): ACCOUNT (avatar chip → opens AccountModal), DEPOSIT +1000 kiosk (disabled/"…" while pending, `bell()` on claim — same toast), VERIFY, LOGOUT, STAFF (role-gated); guests get LOGIN instead of ACCOUNT/LOGOUT.
- Cleanup: delete `MachineCard`, `LiveTableCard`, `PokerTableCard`, `CrashTableCard`, `CARD_BASE`, `cardHover`, `CardHeader`, `StateBadge` from page.tsx; keep `tierGlow` (crash node still uses it).

### Animations & effects (flashy but crisp — hard neon edges, no soft glow blobs)

- **Fan-in on load**: hub pops via existing `bigPop`; each node flies from the hub to its slot with overshoot easing (`cubic-bezier(.2,1.4,.4,1)`), staggered ~70ms per node, via per-node `--dx/--dy` CSS vars + new `radNodeIn` keyframe; decorative rings scale/fade in.
- **Idle**: slow-rotating dashed outer ring + a crisp `repeating-conic-gradient` sweep ring (hard color stops); live nodes pulse (reuse `hintBlink` + new subtle `radLivePulse` box-shadow pulse).
- **Hover**: node scales ~1.09, border/glow flips to its accent color, icon micro-bounces, `sound.winTick()` per node entered (imperative hover pattern like today's `cardHover`). Nodes remain real `<Link>`/`<button>` elements (keyboard focusable).
- **Hub spin easter egg**: clicking the hub whirls both rings ~720° (`radSpinFast`), rapid tick sounds then `bell()`, nodes do a synchronized wobble.
- **Launch effect**: picking a node zooms it toward the viewer, the rest retract into the hub, a full-screen flash (`radFlash`), then `router.push` (~380ms). `prefers-reduced-motion`: global kill switch covers new keyframes; the delayed push is skipped (navigate immediately).
- Lobby WS updates (rooms appearing/vanishing) recompute ring positions; new nodes replay the fan-in.
