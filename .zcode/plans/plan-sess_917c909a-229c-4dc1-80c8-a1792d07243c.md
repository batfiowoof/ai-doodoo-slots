## 2. Scene engine — new `apps/web/lib/crashScene.ts`
Canvas 2D + `requestAnimationFrame` loop (replaces the current redraw-per-100ms-tick):
- **Multi-layer parallax starfield**: scroll speed and star streak length scale with multiplier — stars stretch into velocity lines at speed.
- **Ship**: server ticks (100ms) set a target; rAF interpolates for smooth motion. Sprite state escalates by multiplier thresholds (~1.5×/3×/6× → tilt sprite at 10×+). **Zoom-out**: ship starts large (~2.5×) and shrinks toward ~0.75× as the multiplier climbs (camera pulling away), with subtle wobble and diagonal drift at high multipliers.
- **Phases**: `betting_open` = ship docked on pad w/ idle flame + T-minus countdown; `locked` = ignition rumble/shake build-up; `running` = launch + zoom-out + escalating effects; `settled` = crash sprite sequence with debris particles.
- **Full arcade chaos**: screen shake scaled to multiplier/events, warp-flash on 2×/5×/10×/25× milestones, chromatic glitch jitter at 10×+, exhaust particles, CRT flicker. All toned down under `prefers-reduced-motion`.
- **Altitude gauge** (bottom strip): retro oscilloscope-style multiplier curve with glowing tip dot, auto-cashout tick marker, crash point marked red.
